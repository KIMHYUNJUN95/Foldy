# 05. 화이트 리디자인 — 시안 · 규칙 · 바뀌는 동작

> 상태: **시안 작업 중 (2026-10-09)** — 코드에는 아직 반영하지 않았다. 리디자인이 전부 끝날 때까지 커밋 · 푸시하지 않는다(사용자 결정).
> 시안: Claude Design 캔버스 「Foldy 화이트 리디자인 시안」 — https://claude.ai/artifact/KSbt6Y4R8YXUVCLtFNPfKF

아이보리 바탕을 **흰 바탕**으로 바꾸고, 대시보드(PC)와 모바일(폰 · 폴드 · 태블릿 가로)을 함께 다시 그린다. UI/UX 의 큰 흐름은
유지하되, 화면마다 사용자가 고른 개선을 반영했다. 이 문서는 (1) 시안에서 확정한 시각 규칙과 (2) **구현할 때 실제 동작이나 데이터가
바뀌는 항목**을 모아 둔다. 구현할 때는 각 기능 문서도 함께 고친다(CLAUDE.md 규칙 3 · 9).

## 1. 시각 규칙 (확정)

- 바탕 흰색, 포인트 보라 `#7A52E6`(눌림 `#5A30CF`). 글꼴 Geist + Noto Sans KR, 숫자는 tabular-nums.
- **세로 구분선을 쓰지 않는다.** 가로선만, 필요한 곳에만. 예외: 예약 캘린더 그리드의 날짜 구분 세로선(아주 연하게 `#F1F1F4`).
- **박스로 감싼 구역을 만들지 않는다.** 카드 테두리 · 회색 카드 묶음 · 점선 테두리 금지. 여백과 가로선으로 이어지는 한 화면.
  입력칸 · 선택 버튼은 테두리 없는 옅은 면(`#F4F4F7` · `#F7F7F9`).
- **색 알약(pill) 금지.** 상태 · 우선순위 · 카테고리는 회색 글자 + 「·」. 빨강은 긴급 · 위험(낮은 평점, 폐기 임박 등)에만.
- 채널은 회사 색: Airbnb `#FF5A5F` · Booking.com `#003B95` · 직접 `#8B8898` · 기타 `#D9D7E0`.
- 선택된 줄은 옅은 보라 배경만(왼쪽 막대 금지).
- 삭제는 「삭제」 글자 대신 **빨간 휴지통 아이콘**, 상세 위쪽(PC 닫기 옆 · 모바일 상태 줄 끝).
- 금액은 줄이지 않고 전부 숫자(¥55,769,568). 숫자와 단위 사이 4px.
- 옆으로 넘기는 탭 줄에 스크롤바를 보이지 않는다. 키보드 단축키 안내는 그리지 않는다.
- 대지 아래 빈 공간을 남기지 않는다(PC 관리자 대지는 사이드바 때문에 1060 아래로 줄이지 않고 내용으로 채운다).
- **PC 관리자 사이드바는 64px 아이콘 레일**이고 마우스를 올릴 때만 248px 로 펼쳐져 본문 위로 뜬다(지금 앱 규칙 그대로 — `05-admin-web-ia.md`, 사용자 재확인 2026-10-09). 시안의 PC 대지도 전부 레일로 그린다.
- 모바일 메뉴는 지금처럼 **화면 전체를 덮는 메뉴**(반쪽 서랍 아님 — `16-mobile-navigation.md`).

## 2. 구현할 때 바뀌는 동작 · 데이터

시안에서 고른 개선 가운데 지금 앱과 동작이나 데이터가 달라지는 것. 구현 순서는 리디자인 완료 후 정한다.

| 기능 | 바뀌는 것 | 고칠 문서 |

| 수리/점검 | 요청 목록 종류 필터를 글자 탭으로 | 08 |
| 분실물 | 관리자 뷰 4개 → 3개(보관 중 · 반환 · 폐기 내역), 현황 보드 → **보관 타임라인**(14일 막대 · D-day) | 09 |
| 주문/비품 | 관리자 뷰 4개 → 3개(처리 중 · 배송 캘린더 · 전체 기록), 보드 → **처리 큐**(줄마다 다음 버튼) + **이번 주 배송 줄**. 쇼핑몰 링크는 색 배지 대신 회색 글자 | 10 |

| 알림 | **오늘 · 이번 주 · 이전 묶음**, **알림 지우기**(골라서 = 바로 / 모두 = 하단 시트로 확인) — 상세 규칙 `14-notification-design.md` 「알림 지우기」 | 14 |

## 3. 진행 상황

확정: 로그인 · 이메일 로그인/가입 · 약관 · 온보딩 · 대시보드 · 청소 · 근태 · 수리/점검 · 분실물 · 주문/비품 · 린넨 반품 ·
게스트 피드백 · 채용 · 사용자 · 예약 캘린더 · 공지 · 게시판 신고 · 투두이스트 · 설정 · 가동률 · 매출 · 자동화 · 룸 링크.
모바일 전용 화면(알림 · 계정 · 제안함 · 버그 신고 · 메뉴)도 확정.
남은 하위 화면(근태 모바일 폰 · 폴드 · 태블릿, 청소 기록 PC)도 확정.
판매 캘린더: 39장 시안 작성(PC 18 · 폰 16 · 폴드 2 · 태블릿 2 — 30일 · 월간 · 필터 · 사이드바 펼침 · 가격 수정/확인 · 최소숙박 · 차단/확인 · 예약 상세/수정/취소 · 수기 예약 · 취소만 보기 · 가격 개입 · 최근 예약 · 이력 · 매출 요약 · 이력 카드 · 반영 알림 · 날짜 시트) — 사용자 확인 대기. 전표는 기능 미구현이라 건너뜀.

## 4. 구현 진행 (작업 트리 `.claude/worktrees/white-redesign`, 커밋 전)

- 공용 색 토큰: 앱 `globals.css` · 관리자 `admin-console.css` 를 흰 바탕 · 보라(#7A52E6)로. 하드코딩 아이보리 · 남색 27개 파일 교체.
  관리자 사이드바 에스프레소 → 흰색(선택 = 옅은 보라, 왼쪽 막대 없음). 하단 탭 바 흰색 · FAB 단색 보라. 매니페스트 · 테마색 · 시작 화면 흰색.
- 로그인 · 이메일 로그인 · 가입 · 비밀번호 재설정 · 차단 안내: 브랜드 패널을 없앤 흰 한 장(`auth-frame.tsx` + `auth-white.css`, 옛 `auth-console.css` 삭제).
  넓은 화면(≥ 1200px)은 머리(로고 · 「운영 콘솔」 · Language — 「문제가 있나요?」는 바닥 「도움말」과 겹쳐 뺌) + 가운데 400px + 바닥(직원 전용 · 약관), 좁은 화면은 한 단.
  **바뀐 동작:** 첫 화면에서 이메일을 받아 이메일 로그인으로 넘김, 이메일 로그인 화면의 Google 버튼 제거(첫 화면에만), 가입에 **비밀번호 확인 칸 + 조건 체크(10자 · 영문 · 숫자)**
  (서버도 확인 칸이 오면 일치 검사 — `password_mismatch`), 언어 버튼은 어느 언어든 「Language」.
- 온보딩(폰 마법사): 흰 바탕(아이보리 방사 그라데이션 제거) · 단색 보라 버튼 · 칸 나눈 진행 막대(뒤로 ‹ · n/6) · 제목 700 굵기 ·
  상자 카드 대신 열린 목록, 팀 확인 카드는 옅은 회색 면 + 검정 조직 칸, 시작 화면 위에 로고 · 아래에 「로그인으로 돌아가기」.
- 온보딩(PC 한 화면 폼): 로그인과 같은 틀(머리 · 왼쪽 단계 · 560px 폼 · 바닥), 구역 상자 없이 가로선 하나, 이름표 걸린 입력칸,
  생년월일 · 성별 · 전화는 테두리 하나로 묶음, 주 버튼 왼쪽 + 「코드 없이 나중에 입력」 오른쪽, 오른쪽 위 「로그아웃」.
- 약관 보기: 로그인 · 가입의 이용약관 · 개인정보 처리방침 링크를 누르면 그 자리에서 연다 — 폰 · 폴드 · **태블릿 = 하단 시트**, **PC = 가운데 팝업**(사용자 결정).
  탭(이용약관 | 개인정보 처리방침) · 요약 회색 면 · 조항 · 「확인」(PC 는 「새 창에서 보기」도). 링크는 진짜 주소라 새 탭으로도 열린다. `BottomSheet` 에 `tabletLayout` 옵션 추가.
- 대시보드 홈(PC): 시안 두 장 그대로(운영 관리자 = 매출 · 가동률 · 최근 6개월 + 그 아래 큐 · 할 일 · 예약 전부 / 그 밖 = 큐 · 할 일 · 예약만), 이상 근태 · 중요 공지 구역 제거, 관리자 머리 줄 흰색.
- 모바일 홈: 상자 없는 한 장(출근 상태 알약 · 큰 타이머 · 현장/시각 면 · 「근태 열기」, 공지 한 줄, 체크인/아웃 큰 숫자, 진행 중 작업 줄, 빠른 실행 옅은 보라 칸,
  오늘 기록 점 줄), 「업데이트 시각」 줄 제거, 폴드 2열 · 태블릿 3열(공지는 인사 줄 오른쪽). 모바일 머리 · 레일 · 사이드바 화이트(16번).
- 청소(PC 오늘 현황 · 기록, 모바일 폰 · 폴드 · 태블릿): 시안 그대로 — 상세는 07번 「화이트 리디자인 (2026-10-13)」. 시안의 사진 · 완료 취소는 기능이 없어 뺐다.
  **공용으로 함께 바뀐 것:** 관리자 필터 줄의 작은 드롭다운(`AdmDropdown size="sm"`)이 상자 없는 「전체 건물 ⌄」 글자 버튼으로,
  오른쪽 상세 패널(`.panel` · `.pblock` · `.kv` · `.locknote` · `.rptile`)이 테두리 · 구분선 없는 흰 면 · 보라 버튼으로 — 모든 관리자 화면에 같이 적용된다.
