# 38. 알바 급여 엑셀 — 지금 쓰는 양식 설계서 (Foldy 로 같은 엑셀을 한 번에 만들기 위한 기준)

> 상태: **분석 · 설계 기준만. 구현 보류**(사용자 2026-10-21 「우선 구현은 하지 말고 외워놔」, 2026-10-22 「나중에 엑셀을 만들 수 있도록 · 한 번에」).
> 원본: 사용자 PC 의 `新アルバイト給与管理YYYYMMDD.xlsx`(2026-10-22 은 `…20261009.xlsx` 기준, 「9月分 · 10/9 支給」). 매달 파일을 복사해 쓴다.
> 이 문서에는 **이름 · 금액 같은 개인 정보를 적지 않는다**(구조 · 수식 · 칸 배치 · 인원 수만).
> 관련: `docs/product/21-attendance-payroll-workflow.md`(Foldy 급여 계산), 메모리 「알바 급여명세서 양식」.

## 1. 한눈에

- 대상: **시급제 알바**(정직원 급여는 세무사). 한 파일 = 한 달 지급분.
- 지급 방식이 둘이다 — **현금(現金)** 과 **계좌이체(振込)**. 입력 시트 · 명세서 시트가 방식별로 **따로** 있다(같은 열 구성).
- 근무 시간 · 출근 일수 · 비과세 교통비는 **다른 엑셀**(`YYYY-MM_급여총액_리스트.xlsx` 의 시트 「급여총액」)에서 **한국 이름으로 VLOOKUP** 해 온다.
  Foldy 가 이 자리를 대신한다(근태 → 시간 · 일수, 교통비 → 비과세 교통비).
- 2026-10-09 파일 인원: 현금 9명 · 이체 29명. 달 중간 시급 변경(時給②) 1명씩. 추가 지급(休日出勤 칸) 이체 2명.

## 4. 원천세 (W)

```
丙 → 0
乙 → 課税計 9,300 이상 105,000 미만: ROUNDDOWN(課税計 × 3.063%, 0)
     그 밖: 세금표 L열(乙) — 課税計가 B(이상) ≤ x < C(미만)인 줄
甲 → 세금표 D열(부양 0명) — 같은 줄 찾기. **부양 인원 열(E~K)은 쓰지 않는다**
표에 없으면(IFERROR) 0
```
- 세금표 데이터는 10~402행인데 **수식은 10~161행만 본다**(§9).
- 표 조회 금액 = 課税計(사회보험 **빼기 전**). 국세청 표 기준은 「사회보험 등 공제 후 금액」(§9).

## 5. 명세서 (現金_明細印刷 · 振込_明細印刷 — 같은 배치)

- A4 세로, 한 페이지에 2명(사람당 **28행**, 28행째 「※ 切り取り線」), 행 높이 13.5, 열 A=3 · B~I=7.5 · J≈9 · K~L=8.5, 인쇄 영역 A:L.
- 사람 n 의 블록 = 행 `28(n−1)+1` ~ `28n`, 입력 시트 행 `n+2` 를 읽는다.

| 블록 행 | 내용 |
| --- | --- |
| 1~2 | 「給与明細書」(A1:D2) · 支給年月(E1:G1, 設定 B4) · 「支給日： 」+B5(H1:J1) · 「検印」(K1:L1, 도장 칸 K2:L4) |
| 3 | 韓国名 · 氏名 |
| 4 | 会社名(A4:J4) |
| 6~11 「支給」 | 時給① · 時給② · 調整分 · 残業手当 / 通勤課税 · 通勤非課税 · 休日出勤 · 深夜残業(M열) / 支給額① · 支給額② · 課税対象額(P) · 総支給額(AA) |
| 13~18 「控除」 | 健康保険 · 介護保険 · 厚生年金 · 雇用保険 · 社会保険計 · 課税対象額 / 源泉所得税 · 住民税 / 年末調整 · 控除計 · 控除合計 |
| 20~23 「勤怠」 | 出勤日数 · 有給日数 · 欠勤日数 · 出勤時間① · 出勤時間② / 残業時間 · 休日日数 · 休出時間 |
| 25~26 「記事」 | 支払方法 · 給与振込(AI=「振込」이면 差引, 아니면 0) · 現金支給額(AI=「現金」이면 差引) · 差引支給額 |
| 28 | ※ 切り取り線 |

- 칸은 대부분 2~4칸 병합(블록당 약 97개 병합). Foldy 엑셀은 같은 병합 · 같은 라벨 위치로 만든다.

## 6. 社長確認用・資金準備表

- 2행 결재 칸 「専務」 G2 · 「社長」 H2. 5행 열 이름: 時給 · No · 韓国名 · 氏名 · 内容 · 金額(税込) · 支払方法 · 出勤日数 (+ I 甲乙).
- 6행 「振込アルバイト（N名 / 50名枠）」 → 7~35행 이체 사람(입력 3~31행) → 36행 「振込合計」 `SUM(F7:F35)`.
- 38행 「現金手渡アルバイト（N名 / 50名枠）」 → 39~81행 현금 사람 → 82행 「現金合計」 `SUM(F39:F81)`.
- 84~86행: 振込合計 · 現金合計 · 総合計(= 준비할 금액). 금액 = 差引支給額(AB), 出勤日数 = AC & 「日」 & (備考 있으면 「 / 備考」).
- (손으로 적은 메모 칸이 하나 있다 — 매달 바뀌는 메모, 구조 아님.)

## 7. 支給確認一覧 · 勤務表チェック用

- 支給確認一覧: 区分(AI) · No · 韓国名 · 氏名 · 出勤日数 · 差引支給額 · 支払方法 · 封入確認(未/済) · 本人確認(未/済) · 備考. 현금 행 → 이체 행 순.
  104~106행 `SUMIF(区分,"振込")` · `SUMIF(区分,"現金")` · 합.
- 勤務表チェック用(숨김): 区分 · No · 韓国名 · 氏名 · 本人記入時間 · 給与入力時間(E+H) · 時間差 · 本人記入日数 · 給与入力日数 · 日数差 · 確認(未/済) · 備考 · 金額.
  105행 確認済件数 `COUNTIF(済)` · 106행 時間差あり `COUNTIF(<>0)`. 조건부 서식 2개.

## 8. 매달 쓰는 법 (印刷方法 시트)

1. 파일을 복사해 이름만 새 달로. 2. 바꾸는 곳은 設定 B4(支給年月) · B5(支給日)뿐. 3. 입력은 두 입력 시트만, 시트 · 행 삭제 금지.
4. 시간은 `53:32` 처럼(24시간 넘어도 됨). 5. 명세서는 두 명세서 시트에서 인쇄. 6. A4 세로 · 한 장 2명 · 가운데 절취선.
7. 자르기 전에 오른쪽 위 「検印」에 社長印 · 確認印. 8. 差引支給額은 10엔 단위 올림.
- 실제 지급일: 10일이 휴일이면 앞당김(예 10/10 토 → 10/9).

## 9. 엑셀 자체의 문제 (2026-10-22 점검) — Foldy 는 따라 하지 않는다

| 문제 | 지금(현금 9 · 이체 29) 영향 |
| --- | --- |
| 현금 명세서 **5번째 사람** 칸에만 남은 「所得税調整」 항목 값이 `#REF!` | **있음** — 인쇄하면 그 사람 명세서에 오류 |
| 사장 확인표 이체 칸 29명뿐(입력 3~31행) — 30번째부터 표 · 「振込合計」 · 「総合計」에서 빠짐 | 딱 29명 — **1명 늘면 합계 틀림** |
| 이체 입력에서 한 줄이 지워져 49칸 · 33~34행 수식이 윗줄을 봄 · 이체 명세서 30번째부터 한 칸씩 밀림 · 근무표 체크 · 支給確認一覧 32~33행 중복 | 30명 넘으면 틀림 |
| 사장 확인표 현금 칸이 입력 13~19행을 안 읽음 | 현금 11명 넘으면 틀림 |
| 현금 입력 M열 이름은 「住宅補助」인데 명세서 라벨은 「深夜残業」 | 지금 M열 비어 있음 — 넣으면 명세서에 다른 이름으로 찍힘 |
| 원천세 수식이 세금표 161행(課税計 50만엔 언저리)까지만 봄 — 그 위는 0 | 알바 월 50만엔 넘을 때만 |
| 원천세를 사회보험 빼기 **전** 금액으로 조회(표 기준은 뺀 뒤) | 알바 사회보험이 비어 있어 지금은 같음 — 사회보험 넣는 사람은 세금이 많게 |
| 숨김 근무표 체크 시트 58행 등에 `#REF!` | 지급액 영향 없음 |
| 印刷方法 「今回設定」 줄이 5月分으로 남음 | 표시만 |

## 10. Foldy 로 만들 때 기준 (구현할 때)

- **현금 / 이체**: 사람별 「지급 방식」 값(기본은 마지막 방식)을 두고, 한 번에 두 입력 시트 · 두 명세서 시트를 같은 배치로 만든다. 인원 칸 수 제한을 두지 않는다(사람 수만큼 행 · 블록).
- **숫자 출처**: 시간①② · 출근일수 = 근태(시급 구간별로 나눠 時給①② · 時間①②), 通勤非課税 = 승인된 교통비, 休日出勤(정액 추가 지급) = 추가수당
  (Foldy 의 「일반 추가수당 / 특별수당」을 어느 칸에 넣을지 **구현 전에 사용자 확인** — 지금 엑셀은 休日出勤 칸 하나만 씀).
- **계산식 일치**: 支給額 = 시급 구간별 ROUND(엔), 課税計 · 支給額合計 · 控除合計 같은 합, 원천세 갑(부양 0명) · 을(3.063% 구간 포함) · 병,
  **실수령 10엔 올림**(Foldy 지금은 총액 올림 — 맞춰야 함). §9 의 문제(세금표 범위 · 사회보험 후 금액)는 고쳐서 만든다(사용자 확인).
- **수동 칸**: 調整分 · 残業手当 · 深夜残業/住宅補助 · 通勤課税 · 社会保険 · 住民税 · 年末調整 · 有給/欠勤 등 · 甲乙丙 — Foldy 에 입력 자리를 두거나 엑셀에서 비워 둔다(사용자 확인).
- 사장 확인표 · 支給確認一覧 · 근무표 체크(Foldy 근태와 본인 기록 대조)도 같은 파일에 함께.
- 내보내기는 관리자 콘솔 공용 규칙을 따른다(`CLAUDE.md` 4b — Excel · PDF 함께, 서버에서 언어 결정). 다만 이 파일은 **일본어 고정 양식**이라 라벨 언어는 원본 그대로.
