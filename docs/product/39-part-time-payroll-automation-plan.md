# 39. 알바 급여 자동화 — 기획 (엑셀 양식 전부를 Foldy 로)

> 상태: **기획 확정 전(결정 대기 §11)** · 구현 안 함. 2026-10-22 사용자 「기획부터 처음부터 끝까지 마무리부터 · 지금 보이는 엑셀 양식은 전부 빠짐없이 구현」.
> 목적: 지금 사람이 손으로 하는 알바 급여 일(엑셀 `新アルバイト給与管理`)을 Foldy 가 **자동으로** 하게 한다. 엑셀은 **설계 참고 양식**이다 —
> 엑셀 자체의 오류(칸 수 제한 · 줄 밀림 · `#REF!`)는 따라 하지 않는다.
> 양식 분석: `docs/product/38-part-time-payslip-excel-spec.md`. 지금 급여 계산: `docs/product/21-attendance-payroll-workflow.md`.

## 0. 원칙

1. **엑셀의 모든 시트 · 열 · 칸이 Foldy 에 대응한다**(§2 표에 빠짐없이). 「안 함」은 이유와 함께 적는다.
2. 사람이 하던 일은 **자동 · 기본값**으로, 남는 손 입력은 **한 화면 한 표**에서 끝낸다(엑셀 입력 시트와 같은 열 순서).
3. 숫자는 **엑셀과 1엔도 다르지 않게**(같은 반올림 · 올림). 9월분 실제 엑셀 값으로 맞춰 보는 테스트(§10).
4. 출력은 **엑셀 + PDF**(관리자 콘솔 규칙 4b). 엑셀은 원본과 **같은 시트 이름 · 순서 · 칸 배치(일본어 고정 양식)** — 지금 받아 보는 사람(사장 · 専務 · 세무 · 알바)이 그대로 쓸 수 있게.
5. 화면 문구는 ko · ja · en. 돈 · 개인정보는 권한 키로만(§8).

## 1. 한 달 흐름 — 지금(사람) → Foldy

| 단계 | 지금(엑셀) | Foldy |
| --- | --- | --- |
| ① 근무 집계 | 다른 엑셀(급여총액 리스트)에 시간 · 일수 · 교통비 정리 | **자동** — 앱 출퇴근 · 승인된 교통비 |
| ② 새 달 파일 | 파일 복사 · 設定 B4 · B5 수정 | **자동** — 달을 고르면 支給年月 · 支給日(10일, 휴일이면 앞당김) |
| ③ 사람 넣기 | 현금 / 이체 시트에 한국 이름 · 일본 이름 · 시급 입력 | **자동** — 그 달 근무한 시급제 전원, 사람별 설정(§3-A)으로 현금 / 이체 · 甲乙丙 |
| ④ 시간 · 지급액 | VLOOKUP + `ROUND(시급×시간)` | **자동** — 시급 구간별(①②…) |
| ⑤ 수당 · 공제 손 입력 | 調整分 · 残業手当 · 休日出勤 · 社会保険 · 住民税 · 年末調整 … | **급여 준비 화면 한 표**(§5-A)에서 입력, 추가수당은 이미 Foldy 에 있는 것 자동 |
| ⑥ 원천세 · 실수령 | 수식 | **자동**(§4) |
| ⑦ 근무표 대조 | 숨김 시트에 본인 기록 붙여 차이 확인 | **자동** — 본인 출퇴근이 곧 근무 기록. 정정 요청 · 손 수정 · 마감 후 변경만 「확인 필요」(§5-D) |
| ⑧ 결재 | 사장 확인표 인쇄 → 専務 · 社長 도장 | **결재 기록** + 사장 확인표 엑셀 · PDF(§5-C) |
| ⑨ 명세서 | 명세서 시트 인쇄 · 検印 · 절취 | 명세서 엑셀 · PDF(현금 / 이체, A4 2명, 検印 칸) |
| ⑩ 지급 확인 | 支給確認一覧에 봉투 · 본인 확인 체크 | **화면에서 체크**(누가 · 언제) + 목록 출력 |
| ⑪ 보관 | 파일 저장 | **월 마감 스냅샷**(지금 근태 마감 확장) — 나중에 다시 뽑아도 같은 숫자 |

## 3. 새로 받는 데이터

### 3-A. 사람별 급여 설정 (시급 화면 옆, 이력 없이 「지금 값」 + 변경 기록)
- **지급 방식**: 현금 / 계좌이체(기본 이체?) — §11-1
- **원천세 구분**: 甲 / 乙 / 丙(기본 乙?) — §11-1
- **부양 인원**(甲일 때 0~7, 기본 0) — §11-5
- **일본 이름(氏名)** — 명세서 · 사장표 · 세무용
- (선택) 사회보험 가입 여부 · 주민세 월액 — 매달 표에 미리 채우는 기본값

### 3-B. 달마다 사람별 손 입력 (급여 준비 화면 한 표)
- 지급: 調整分(±) · 残業手当 · M열 항목 · 通勤課税(규칙 밖일 때)
- 공제: 健康保険 · 介護保険 · 厚生年金 · 雇用保険 · 住民税 · 年末調整(±) · 源泉所得税 덮어쓰기(사유)
- 근태 보충: 欠勤日数 · 残業時間 · 休日出勤日数 · 休出時間(자동 아닌 것만)
- 支払方法 그 달만 바꾸기 · 備考
- 저장 = 그 달 「급여 준비 값」(마감 전까지 고침, 마감 때 스냅샷에 같이 굳힘)

### 3-C. 회사 설정
- 会社名(명세서 표기), 지급일 규칙(매월 10일 · **휴일이면 앞당김** — 일본 공휴일 달력), 현금 / 이체 기본값, 결재자(専務 · 社長)

### 3-D. 세금표
- 연도별 `源泉徴収税額表` — 月額表(甲 0~7명 · 乙) + 日額表 丙 · 구간(이상 · 미만). 국세청 표 그대로 넣고, **새해 표가 없으면 마감을 막고 알림**.

## 4. 계산 규칙 (엑셀과 1엔 일치)

### 4-A. 순서
```
시급 구간별 시간 h_k(분 합계 → 시각값) , 支給額_k = ROUND(시급_k × h_k)      ← 엑셀과 같게: 구간별 월 합계 시간에 곱하고 엔 반올림
課税計 P   = Σ支給額_k + 調整分 + 残業手当 + 休日出勤 + M항목 + 通勤課税
支給額合計 Q = P + 通勤非課税
社会保険計 V = 健康 + 介護 + 厚生年金 + 雇用
源泉税 W   = §4-B
控除合計 Z = V + W + 住民税 + 年末調整
差引 AB    = CEILING(Q − Z, 10)       ← 실수령 10엔 올림
```
- **지금 Foldy 와 다른 점**: (1) 근무 1건마다 분 버림 → 구간별 월 합계 분으로(초 단위는 버림 위치 §11-10), (2) 총액 10엔 올림 → **실수령** 10엔 올림.
  기존 「근태 급여 화면 · 내보내기」 숫자도 같이 바뀐다 — 마감된 달은 그대로, 새 규칙은 적용 시작 달부터(§11-10).

### 4-B. 원천세
- 丙(日雇い · 2개월 이내 단기) → **근무한 날마다** 日額表 丙 열로 계산해 한 달 합계(하루 9,300엔 미만인 날은 0).
  엑셀은 丙을 무조건 0 — 하루 9,300엔 넘는 날이 있으면 틀림(§11-12). 출력 엑셀에 日額表 丙 시트도 같이 넣는다.
- 乙 → 課税計(또는 §11-5 의 사회보험 뺀 금액) 9,300 이상 105,000 미만: `ROUNDDOWN(x × 3.063%)`, 그 밖은 표 乙 열.
  **「9,300 미만 = 0」은 엑셀에만 있는 규칙** — 丙의 하루 기준(9,300엔)이 잘못 옮겨진 것으로 보임, 국세청 월액표 乙엔 없음(§11-12). 확인 전까지는 엑셀과 같게.
- 甲 → 표의 부양 인원 열(엑셀은 0명 고정 — §11-5).
- 표 조회: 구간 `이상 ≤ x < 미만`, **표 전 구간**(엑셀처럼 50만엔에서 끊기지 않음). 표 범위를 넘는 고액은 국세청 산식 — §11-5.

## 5. 화면 (관리자 웹 — 근태 › 급여 아래, PC · 폰 · 폴드 · 태블릿)

- **A. 급여 준비 (달별 표)**: 엑셀 입력 시트와 같은 열 순서의 표 하나 — 자동 칸은 회색 잠금, 손 칸만 입력. 위쪽 탭 「현금 n명 · 이체 m명」.
  합계 줄 · 「지난달 값 이어 쓰기」 · 저장 상태 · 오류(세금표 없음 · 일본 이름 없음 · 甲乙丙 없음) 표시.
- **B. 사람별 급여 설정**: 시급 화면에 지급 방식 · 甲乙丙 · 부양 · 일본 이름 칸.
- **C. 결재**: 「사장 확인표」 화면 — 이체 / 현금 목록 · 합계 · 総合計 → 専務 결재 → 社長 결재(순서 · 되돌리기). 결재 뒤 값 바꾸면 결재 풀림.
- **D. 확인 필요**: 정정 요청 미처리 · 손 수정 · 마감 후 변경 · 시간 0 인 사람 — 지금 근태 마감 차단과 합침.
- **E. 지급 확인**: 사람별 「봉투 넣음 · 본인 확인(현금) / 이체 완료(이체)」 체크(누가 · 언제), 다 되면 그 달 「지급 완료」.
- **F. 출력**: 한 번에 「급여 엑셀(10시트 전체)」 · 「명세서 PDF(현금 / 이체)」 · 「사장 확인표 PDF」 · 「지급 확인 목록 PDF」.
- (뒤 단계) 알바 본인 앱에서 내 명세서 보기 — §11-11.

## 6. 출력 파일 규격

- 엑셀: 원본과 같은 10시트 · 같은 이름 · 순서 · 열 너비 · 병합 · 인쇄 설정(명세서 A4 세로 2명 · 28행 블록 · 행 나눔), 값 + **같은 수식**(엑셀에서 손 고쳐도 다시 계산).
  외부 파일 VLOOKUP 은 값으로 대체. 사람 수 제한 없음.
  **수식 흐름은 원본 그대로**: 입력 시트(현금 · 이체)에서 F · I · P · Q · V · W · Z · AA · AB 를 계산 → 명세서 블록 n 은 입력 시트 `n+2` 행을 참조,
  사장 확인표 · 支給確認一覧 · 勤務表チェック 도 입력 시트를 참조 → 입력 칸 하나만 고쳐도 명세서 · 합계가 같이 바뀐다.
  Foldy 화면의 계산 엔진과 엑셀 수식은 같은 규칙(§4) — 골든 테스트에서 둘 다 대조. 파일 이름 `新アルバイト給与管理YYYYMMDD.xlsx`(지급일).
- PDF: 명세서(현금 · 이체 따로, A4 2명 · 절취선 · 検印), 사장 확인표, 지급 확인 목록 — 엑셀과 같은 숫자.
- 둘 다 마감 스냅샷에서 만든다(다시 뽑아도 같은 숫자).

## 7. 엑셀 오류 처리 (따라 하지 않음)
`#REF!` 칸 · 50/49칸 제한 · 줄 밀림 · 사장표 29명 · 현금 13~19행 누락 · M열 라벨 불일치 · 세금표 161행 끊김 — 모두 Foldy 에선 생기지 않게. 세금 조회 기준(사회보험 전/후)은 §11-5.

## 8. 권한 (이미 있는 키 + 하나)
- 급여 준비 보기 · 출력 = `payroll.view` · 입력 · 마감 = `payroll.manage` · 사람별 설정 = `wages.manage` · 교통비 = `transport.manage`.
- **새 키 `payroll.approve`(급여 결재)** — 기본 대표 · 전무(専務 · 社長 결재). 사람마다 켜고 끔.
- 지급 확인 체크 = `payroll.manage`(또는 별도 키 §11-9).

## 9. 데이터 (설계 개요 — 구현 때 마이그레이션)
- `payroll_member_settings`(조직 · 사람 · 지급 방식 · 원천세 구분 · 부양 · 일본 이름 · 변경 기록)
- `payroll_month_inputs`(조직 · 사람 · 달 · 손 입력 칸들 · 메모 · 지급 방식 덮어쓰기)
- `payroll_month_approvals`(조직 · 달 · 단계 専務/社長 · 누가 · 언제 · 상태)
- `payroll_payment_checks`(조직 · 사람 · 달 · 봉투 · 본인 확인 · 이체 완료 · 누가 · 언제)
- `withholding_tax_tables`(연도 · 月額表 구간 · 甲 0~7 · 乙) + 日額表 丙(연도 · 하루 구간 · 세액)
- `org_payroll_settings`(会社名 · 지급일 · 공휴일 앞당김 · 결재자)
- 월 마감 스냅샷(`attendance_month_snapshots`) 확장 — 위 값을 그 달 확정본으로.
- RLS: 전부 조직 범위 + 위 권한 키(`can_view_payroll` 계열).
